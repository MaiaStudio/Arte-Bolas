# Arte Bola Balões — Arte & Cenografia com Balões

> Estúdio especializado em transformar balões em instalações artísticas, cenários e experiências visuais marcantes. Desde 1999 em Fortaleza, Ceará.

## ✨ Sobre o Projeto

Website interativo da **Arte Bola Balões**, com portfólio visual dinâmico, animações fluidas com Three.js & GSAP, experiência imersiva e responsiva para clientes explorarem projetos e solicitarem orçamentos.

## 🚀 Tecnologias

- **Vite** + **TypeScript**
- **Tailwind CSS**
- **Three.js** & **GSAP** (animações e efeitos interativos)
- **Lucide Icons**

## 💻 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/MaiaStudio/Arte-Bolas.git
   cd Arte-Bolas
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Build para produção:
   ```bash
   npm run build
   ```
